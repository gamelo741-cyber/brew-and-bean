# Brew & Bean ☕

A modern coffee shop website inspired by coffee shops in Riyadh.

## Live Demo

https://brew-and-bean.gamelo741.workers.dev/

## Features

- Responsive design
- English / Arabic language support
- RTL / LTR support
- Dark / Light mode
- Modern coffee shop UI
- Responsive navigation

## Built With

- React
- TypeScript
- Vite
- Tailwind CSS
- CSS
- Git & GitHub
- Cloudflare Workers

## Project

Brew & Bean is a frontend project created to practise building
responsive and modern web interfaces with React and TypeScript.
